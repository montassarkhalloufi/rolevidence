documents, scripted model results and French synthetic speech. No provider was
called and no private dossier was accessed. The visible banner identifies simulated
results. This is a product tour, not a model accuracy or performance benchmark.

platform-specific production scripts are not needed to build, test or use the
application and are excluded from the source repository. The transcript and
captions remain versioned for accessibility. The owner retains the production
materials privately for future video updates.
